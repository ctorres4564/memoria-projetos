# AGENTS.md

## Objetivo

Este vault é a memória permanente de todos os projetos.

Antes de iniciar qualquer tarefa, o agente deve ler:

1. Contexto
2. Estado Atual
3. Decisões
4. Diário do Projeto

na pasta do projeto correspondente.

---

## Ao finalizar qualquer tarefa

Atualizar obrigatoriamente:

- Estado Atual
- Diário do Projeto

Se houver mudança arquitetural, registrar também em:

- Decisões

---

## Nunca

- apagar histórico
- remover decisões antigas
- substituir informações sem justificativa

Sempre acrescentar novas informações preservando o histórico.

---

## Organização

Cada projeto possui sua própria pasta contendo:

- Contexto
- Estado Atual
- Diário do Projeto
- Decisões
- demais documentos

---

## Git

Sempre que alterações relevantes forem concluídas:

- realizar commit
- escrever mensagem clara
- sincronizar com GitHub

---

## Princípio

A memória do projeto deve ser suficiente para que qualquer agente continue o desenvolvimento exatamente do ponto onde outro agente parou.
